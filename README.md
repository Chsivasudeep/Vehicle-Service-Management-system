Vehicle Service Management System
Overview
A simple Python-based project to manage vehicle servicing, customer details, service selection, and bill generation using Object-Oriented Programming (OOP).

Features
Customer Registration: Register customers with unique customer IDs.
Vehicle Management: Add vehicles linked to registered customers.
View Details: Search customers and view registered vehicles.
Service Selection: Choose services based on vehicle type (Bike, Car, or Truck).
Bill Generation: Display the selected service and total cost.
Interactive Menu: Navigate through the application using a command-line menu.
Technologies Used
Python
-->OOP (Classes and Objects)
-->Python Modules: random, string
-->How to Run
-->Install Python 3.

Save the code as main.py.

Run the following command:

python main.py
Note
This project stores data in memory using Python lists. Data is not permanently saved after the program closes.
